# MEGARes_v4_manuscript_code

This repository contains detailed information on bioinformatic and statistical analysis performed in "MEGARes 4.0 and AMR++ 4.0: expanded, flexible resources for comprehensive resistome characterization in high-throughput analysis of metagenomic data". Included are several directories, each containing different content. 

Generate_mock_metagenomes/ contains a detailed description of how mock metagenomic samples used for SNV benchmarking were produced. Additionally, it contains the code for generating the SNV analytic matrices used in recall and precision analysis. 

Analyze_SNV_Metrics/ Contains the two R files used to prepare "ground truth" inputs, and perform recall and precision analysis on SNV data.
